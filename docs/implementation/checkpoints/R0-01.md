upstream base is independently red in OpenAI's own Actions run, so an untouched
green result does not exist reliably for that exact SHA. The kickoff directive
requires an exact conformance test and the smallest safe adaptation when the
live repository differs from the specification's assumption. The accountable
decision is therefore to keep the current upstream base and accept a Class A,
test-only hermeticity patch rather than select an older base or mask the network
and terminal dependencies in an external shell environment.

`ac8d1f10500174124dbd65ca130cca5e673dadac2bdd8a1c62863f36d284f513`.

the changed oracles remove ambient I/O/timing and strengthen raw ANSI detection.
The untouched-base failure remains preserved in release evidence. This is a
recorded live-compatibility adaptation, not a quality-gate waiver.
