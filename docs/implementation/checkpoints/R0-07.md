## Security invariants

- Candidate-owned GitHub Actions cannot be the authority accepted by branch
  protection. Required context `studio/release-gate` must be rebound from
  general Actions App ID `15368` to a dedicated non-Actions attestor App. Its
  latest exact-head CheckRun must be completed/success, use the candidate hash
  as `external_id`, and attach the exact canonical manifest through the fixed
  title, digest summary, and base64 text contract.
- The dedicated App private key and every installation token remain entirely
  outside repository Actions. The App has only Metadata read, Contents read,
  Actions read, Pull requests read, and Checks write; it has no Contents write,
  Pull requests write, or Administration write. Post-merge failure emits a
  bounded action-required receipt instead of mutating a revert pull request.
- No publication credential reaches a pull-request workflow or candidate child.
- No protected Linear credential is used by R0-07.
- Generated candidate/package/review/test/publication evidence lives outside
  the checkout until intentionally transported as a workflow/release artifact.
- Package children strip secret-shaped environment names; artifacts contain
  public version/provenance only.
- A draft is publicized only after exact remote inventory, downloaded-byte
  verification, and build-provenance attestation over the final asset set.
  Before the irreversible command, the finalizer atomically writes an in-flight
  receipt, then advances or fails it after every remote verification phase.
  Every available receipt is preserved under `always()`. On success, the exact
  canonical pass receipt becomes the custom attestation predicate for immutable
  `release-manifest.json`, and predicate equality is verified; this attestation
  is not another mutable release asset.
- Cross-attempt artifact names flow from the successful producer jobs, and
  immutable evidence excludes wall-clock response fields. Any active or merged
  manual release revert blocks publication; automation does not create, close,
  delete, or merge it.
