# Pinned Codex App Server schemas

This directory contains raw protocol artifacts generated by the exact Codex
build recorded in the repository root `CODEX_VERSION` and `CODEX_LOCK.json`.
They are the request-shape contract for Symphony Studio; current online
documentation is guidance and does not replace this pin.

For each version, the repository retains stable and `--experimental` JSON
Schema and TypeScript trees. Experimental artifacts are capability-discovery
evidence only. Their presence does not make an experimental method or field a
runtime dependency.

Generate and verify from the repository root:

```bash
python3 scripts/codex_schema.py generate --codex codex --tested-at YYYY-MM-DD
python3 scripts/codex_schema.py seal-fixtures --tested-at YYYY-MM-DD
python3 scripts/codex_schema.py verify --installed --codex codex
python3 scripts/codex_schema.py regenerate-check --codex codex
```

Generation deliberately writes an unsealed fixture result. `seal-fixtures`
runs the deterministic schema/App Server/Linear/hermeticity suite and binds its
green result to a normalized source-tree hash. Static verification rejects a
missing or stale fixture seal.

Codex's aggregate V2 JSON generator can vary object-member order between
otherwise identical runs. Raw generated files are retained unchanged; the
verification script hashes parsed JSON using sorted keys and UTF-8, hashes
TypeScript bytes directly, and includes sorted relative paths in every tree and
bundle digest. `SEMANTIC-SHA256SUMS` is therefore a reproducible semantic JSON
and raw TypeScript inventory rather than a raw checksum file for JSON bytes.

The method/field matrix records static presence only. R0-06 separately records
bounded live probes for authentication, models, efforts, service tiers, quota
payloads, identity, emitted events, and enforceable multi-agent limits.
